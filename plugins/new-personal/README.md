# new-personal

Personal engineering taste and code style preferences for human-readable, deletable code, caller-focused error design,
chunked functional pipelines, documented dense code, and codebase untangling.

## Contents

| Path                   | Purpose                                                                                                                                                                                                                             |
|------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `plugin.json`          | Antigravity plugin manifest (`new-personal`)                                                                                                                                                                                        |
| `extension.json`       | Junie extension manifest (`new-personal`)                                                                                                                                                                                           |
| `rules/AGENTS.md`      | Core personal code-style philosophy, project precedence, and skill router                                                                                                                                                           |
| `guidelines/AGENTS.md` | Junie-compatible copy of `rules/AGENTS.md` auto-loaded when installed as a Junie marketplace extension                                                                                                                              |
| `skills/code/`         | `new::code`: Deletable module design, caller-focused error design, native language doc comments, functional pipeline chunking, documented dense code, `python3` structural analysis, co-change untangling, and post-refactor audits |
