# new-framework-web

Web frontend framework and stylesheet guidelines, starting with RSCSS conventions for CSS and SCSS architecture.

## Contents

| Path                   | Purpose                                                                                                |
|------------------------|--------------------------------------------------------------------------------------------------------|
| `plugin.json`          | Antigravity plugin manifest (`new-framework-web`)                                                      |
| `extension.json`       | Junie extension manifest (`new-framework-web`)                                                         |
| `rules/AGENTS.md`      | Precedence rules and router for web framework and stylesheet skills                                    |
| `guidelines/AGENTS.md` | Junie-compatible copy of `rules/AGENTS.md` auto-loaded when installed as a Junie marketplace extension |
| `skills/rscss/`        | `new::rscss`: RSCSS conventions for components, elements, variants, layouts, and helper classes        |
